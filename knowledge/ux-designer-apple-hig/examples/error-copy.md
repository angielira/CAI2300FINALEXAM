# Example: error copy that follows the HIG

Bad: "Error: NetworkError in importScripts".
Good: "**Could not start OpenCV.js.** Check your connection, then try again." [Try again]

Bad: "No contours".
Good: "**No dancer found.** Try a plainer wall, switch the threshold to Manual and move the slider, or turn on GrabCut."

Bad: "IDB blocked".
Good: "**The library is waiting for another tab.** Another tab of this app is still open on an older version. Close the other tabs, then reload." [Reload]
