# Example: the three-step flow (as shipped, 2026-11-23)

1 **Your shape**: drop/choose a photo · Camera with timer · **Add all 16 poses to my library** · ballet pose gallery (16 cards, each with Reference and Attempt).
2 **Compare to**: reference picker (None = outline only) · Threshold Auto/Manual · Clean-up · GrabCut · Ghost · Auto-save · Run again.
3 **Result**: photo with outline → score ring + coach tip → "Looks most like: <pose> · N %" → six measures → Save as reference.
Below: **Library** (Reference shapes | Practice history). Footer: storage used, How it works, Resources, Reset app data.
First-run path in two clicks: Add all 16 poses → Arabesque · Attempt → 75 %, "Looks most like: Arabesque".
Opening an attempt auto-selects the reference with the same pose name, so the score is always against the right pose.
