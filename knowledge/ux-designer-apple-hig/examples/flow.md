# Example: the three-step flow (as shipped)

1 **Your shape**: drop/choose a photo · Camera with timer · 4 samples (reference + attempt for Dip and Styling) · hint: "Open a reference sample and save it, then open its attempt."
2 **Compare to**: reference picker (None = outline only) · Threshold Auto/Manual · Clean-up · GrabCut · Ghost · Auto-save · Run again.
3 **Result**: photo with outline → score ring + coach tip → six measures → Save as reference.
