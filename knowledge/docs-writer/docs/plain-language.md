# Plain language rules

Sources: https://www.plainlanguage.gov/guidelines/ · lecture slides ("muscle, memory and eyes")

- One idea per sentence; active voice; everyday words. Define a term the first time ("a Web Worker, a background thread").
- Lead with what the reader can do; details after.
- The three technologies in one line each: OpenCV.js sees (eyes), WebAssembly makes it fast (muscle), IndexedDB remembers (memory).
- Every claim that comes from a source gets a link; every link the project relies on goes on the Resources page.
